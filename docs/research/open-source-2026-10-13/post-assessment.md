## What is portable into Allworld now

1. **Offline asset lane:** use one TRELLIS.2 or Stable Fast 3D output for a single Lagos landmark/prop, export GLB, then pass it through the existing `src/scene/models/gltf-source.ts` Meshopt loader and the documented deterministic asset pipeline (`docs/ASSETS.md:63-84`). Acceptance must check triangles, primitives/materials, atlas dimensions/bytes, anchors, alpha, and mobile visual scale.
2. **Blender review lane:** MCP for Blender can automate repeatable import, naming, camera, and export tasks, but keep generated scripts and resulting GLBs under human review. It is an authoring tool, not a Vue dependency.
3. **Splat spike:** SuperSplat can inspect/trim a supplied Gaussian splat. Only consider embedding a viewer after a measured fixture proves mobile memory, camera controls, map overlays, and 2D fallback behavior; no evidence here supports replacing the current city renderer.
4. **PBR comparison:** Hunyuan3D-2.1/TRELLIS.2 can be compared offline for one prop’s PBR quality. Allworld currently uses Three `0.180.0`, Standard/Lambert materials, JPEG atlases, and GLTFLoader+Meshopt; neither model automatically supplies Allworld’s lighting, LOD, interaction, or licensing acceptance.

## Claims to reject or qualify

- “3 seconds” is a specific TRELLIS.2 README table result for 512³ on an H100, not a general generation guarantee; the same table gives ~17s at 1024³ and ~60s at 1536³.
- “Open source” does not mean the model weights, outputs, and commercial distribution are all unrestricted. Hunyuan and Stability use community licenses with territory, attribution, use, or revenue conditions; Meshy’s MIT server does not settle Meshy service/output terms.
- “Generates a playable world” does not mean a ready-to-run Allworld scene. HY-World outputs representations that still require conversion, budgets, interaction wiring, and mobile/browser acceptance.
- An MCP connector is a workflow bridge. It does not improve runtime draw calls, animation scheduling, physics, or Three.js rendering by itself.

## Sleep-safe implementation test for the parent

When implementation work resumes, use one fixed Lagos prop and one fixed city/venue camera. Generate or select one candidate offline, preserve the source/license receipt, export GLB, run the existing asset checks, and compare current versus candidate on: first visible asset, triangle/material/texture counts, atlas bytes/dimensions, label/anchor placement, lighting readability, and phone-tier fallback. Stop at missing model/output rights, missing reproducible source, or failure of the current GLB/mobile acceptance gate. This test is deliberately small enough to produce evidence before any engine or pipeline commitment.
