# Credits for Tug

One line for each asset the cartridge lists in `cartridge.ts`, in the same words. The checker reads this file.

- `assets/rope.svg`: our own work, drawn for this example, no third-party material. Licence `ours`.

A CC BY asset needs the exact `attribution` text from its manifest entry written here, for example:

- "Ring by Ada Okafor, CC BY 4.0, https://example.org/ring" (the `attribution` line, copied exactly; the licence page and the source go with it)

CC0 and MIT assets need no credit line, but write the source and author anyway.
